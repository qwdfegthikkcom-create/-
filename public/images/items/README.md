# صور الأصناف

حط هنا صورة حقيقية لكل صنف بنفس الاسم بالضبط (jpg أو png)، والموقع بيستخدمها تلقائياً:

- kebab-mosuli.jpg — كباب موصلي
- tikka-dajaj.jpg — تكة دجاج
- kebab-arabi.jpg — كباب عربي
- dolma.jpg — دولمة
- hummus.jpg — حمص
- kunafa.jpg — كنافة
- baklawa.jpg — بقلاوة
- muhallabia.jpg — مهلبية
- lemon-mint.jpg — عصير ليمون بالنعناع
- chai.jpg — چاي عراقي

لو الاسم .png بدل .jpg، غيّر امتداد الصورة بملف `lib/menu.ts` لنفس الصنف (حقل image).
لحد ما تضيف الصورة، تظهر بطاقة بديلة بلون وأيقونة الصنف تلقائياً بدل ما ينكسر شي بالموقع.

لإضافة صنف جديد بالكامل: افتح `lib/menu.ts` وزيد عنصر جديد بنفس الشكل، وحط صورته هنا بنفس الاسم.

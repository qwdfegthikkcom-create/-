# كافي صيف — Cafe Sayf

منيو وكاشير لمطعم "كافي صيف" (اسم افتراضي، ٢٠ طاولة)، بصفحة واحدة:

- 📱 **المنيو**: يبدأ باختيار رقم الطاولة، ثم تصفح الأقسام (مشاوي، مقبلات، حلويات، مشروبات)، إضافة للسلة مع ملاحظات، وإرسال الطلب.
- 🧾 **الكاشير**: زر بالزاوية العلوية (بدون كلمة مرور)، يعرض الطلبات الجديدة/قيد التحضير/جاهزة للدفع، حالة الطاولات العشرين، طباعة الفاتورة، وتقرير مبيعات اليوم.
- 📴 **يعمل بدون إنترنت** بعد أول فتح (service worker يخزن الصفحة)، والبيانات (الطلبات والمبيعات) تُحفظ محلياً بالمتصفح (localStorage) — بدون سيرفر أو حساب.
- 🎨 هوية بصرية صحراوية (رملي/تراكوتا/ذهبي) بخط عربي طويل (Aref Ruqaa) للعناوين.

## تشغيل المشروع محلياً

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## إضافة صور حقيقية للأصناف

المشروع حالياً يعرض أيقونة بديلة ملونة لكل صنف لحد ما تضيف صور حقيقية.
شوف `public/images/items/README.md` لأسماء الملفات المطلوبة بالضبط.

## إضافة/تعديل أصناف أو أسعار

عدّل ملف `lib/menu.ts` — زيد صنف جديد أو غيّر السعر مباشرة بنفس الشكل الموجود.

## ملاحظة مهمة

هذا البناء "صفحة واحدة" (منيو + كاشير سوا) يشتغل بشكل ممتاز على **جهاز واحد** (مثلاً تابلت عند الكاشير:
الزبون يطلب من نفس الجهاز أو من جهاز ثاني متصل بنفس الشبكة المحلية إذا تم نشره على سيرفر محلي).
إذا احتجت لاحقاً نظام متعدد الأجهزة (كل زبون يطلب من موبايله عبر WiFi داخلي، والكاشير يشوف الطلبات بلحظتها
من جهاز منفصل)، هذا يحتاج سيرفر محلي بسيط بدل الاعتماد على localStorage فقط — أخبرني إذا تريد هذا التطوير.

## النشر

يشتغل مباشرة على Vercel أو أي استضافة تدعم Next.js. بما إنه بدون قاعدة بيانات خارجية،
ما تحتاج أي إعداد إضافي (متغيرات بيئة) للتشغيل الأساسي.
